# 🔐 Секреты и Переменные окружения

Проект использует переменные окружения для настройки подключения к БД, токенов бота и внешних URL.

---

## 📁 Файлы конфигурации

- **`.env`**: Основной файл секретов (находится в корне и в `backend/bot/`). **Никогда не коммитится в Git!**
- **`.env.example`**: Шаблон с пустыми значениями для новых разработчиков.

---

## 🛠 Основные переменные

| Переменная | Описание | Пример |
| :--- | :--- | :--- |
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | `123456:ABC-DEF...` |
| `DB_USER` | Имя пользователя базы данных | `postgres` |
| `DB_PASSWORD` | Пароль от базы данных | `password123` |
| `DB_NAME` | Название базы данных | `ngueu_db` |
| `MINIAPP_URL` | Публичный URL фронтенда (ngrok/domain) | `https://abc-123.ngrok.io` |

---

## 🛡 Безопасность

1. **Игнорирование**: Файлы `.env` и папки `.venv` прописаны в `.gitignore`.
2. **Docker Secrets**: В продакшне рекомендуется использовать Docker Secrets или переменные окружения на уровне ОС сервера.
3. **Ротация**: При компрометации токена бота — немедленно сбросьте его через @BotFather.
