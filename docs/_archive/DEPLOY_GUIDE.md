## 🔑 Доступы и Безопасность

### 1. Доступ по SSH
*   **Хост (IP):** `[ВСТАВЬ_IP_ИЗ_ЯНДЕКС_ОБЛАКА]`
*   **Пользователь:** `ubuntu`
*   **Ключ на твоём Маке:** `~/.ssh/id_rsa` (закрытый) и `~/.ssh/id_rsa.pub` (публичный).
*   **Команда для входа:** 
    ```bash
    ssh ubuntu@[ТВОЙ_IP]
    ```

### 2. Секреты (Файл .env на сервере)
На сервере в папке проекта `/app/ngueu-pomoshnik/` должен быть файл `.env` (не пушится в Git!).
**Минимальный набор:**
```text
BOT_TOKEN=7983893418:AAF... (твой токен)
DB_USER=postgres
DB_PASSWORD=[ПРИДУМАЙ_СЛОЖНЫЙ_ПАРОЛЬ]
DB_NAME=ngueu_db
```

## 🏗 Инфраструктура на сервере

Проект работает в Docker-контейнерах. Всего поднимается 4 сервиса:
1.  **db**: PostgreSQL (База данных).
2.  **api**: FastAPI (Бэкенд-сервис).
3.  **bot**: Aiogram (Telegram бот).
4.  **frontend**: React + Nginx (Mini App и проксирование).

### Основные команды управления:
*   **Запуск/Обновление:** `docker-compose up -d --build`
*   **Остановка:** `docker-compose down`
*   **Просмотр логов бота:** `docker-compose logs -f bot`
*   **Просмотр логов API:** `docker-compose logs -f api`
*   **Статус контейнеров:** `docker ps`

## 🔄 Автоматизация через GitLab (CI/CD)

Чтобы деплой работал автоматически при каждом `git push`, настрой переменные в GitLab (**Settings -> CI/CD -> Variables**):

| Переменная | Значение |
| :--- | :--- |
| `SERVER_IP` | Публичный IP твоего сервера |
| `SERVER_USER` | `ubuntu` |
| `SSH_PRIVATE_KEY` | Содержимое файла `~/.ssh/id_rsa` с твоего Мака |
| `SSH_KNOWN_HOSTS` | Результат команды `ssh-keyscan [ТВОЙ_IP]` |

## 🛠 Начальная настройка нового сервера (Ubuntu 24.04)

Как только зайдешь на новый сервер первый раз, выполни эти команды:

1.  **Установка Docker:**
    ```bash
    curl -fsSL https://get.docker.com -o get-docker.sh
    sudo sh get-docker.sh
    sudo usermod -aG docker $USER
    # После этого нужно выйти и зайти заново (exit и ssh)
    ```

2.  **Клонирование проекта:**
    ```bash
    mkdir -p /app && cd /app
    git clone [ССЫЛКА_НА_ТВОЙ_РЕПОЗИТОРИЙ_GITLAB]
    cd ngueu-pomoshnik
    ```

3.  **Создание папки для вложений:**
    ```bash
    mkdir -p backend/static/uploads
    chmod 777 backend/static/uploads
    ```

## 🛡 Советы по экономии (Яндекс Облако)
*   Используй **Гарантированную долю vCPU: 5% или 20%**.
*   Включи **Прерываемую (Preemptible)** ВМ — это снизит цену в 3 раза. Бот сам перезапустится благодаря Docker.
