# 📜 Журнал изменений (Changelog)

---
## [1.3.1] — 2026-03-14 (Fix & Cleanup)
### ⚙️ Frontend Fixes
- **Config Sync**: `API_BASE_URL` синхронизирован с актуальным ngrok URL (`https://7b56-138-124-61-211.ngrok-free.app`). Это восстановило связь Mini App с базой данных в Telegram.
- **Test ID Removal**: Полностью удалена заглушка ID `927125510` изо всех компонентов (`Home`, `Profile`, `Orders`, `NewOrder`). Теперь приложение работает строго с реальным ID пользователя.
- **Robustness**: Добавлен экран ожидания «Авторизация Telegram...» на время инициализации WebApp API.
- **Social Fix**: Функция «Пригласить друга» теперь имеет fallback-режим (открытие в браузере), если Telegram API недоступен.

### 🛠 Backend Debug Tools
- **Extended Logging**: В эндпоинт профиля добавлены детальные логи (ID запроса, статус в БД, реальное кол-во заказов).
- **Debug Mode**: Добавлена поддержка `DEBUG_MODE` для пропуска авторизации при локальных тестах.
- **Bonus Tool**: Реализован эндпоинт `/api/debug/bonus/{user_id}` для ручного начисления баллов при тестировании.

## [1.3.0] — 2026-03-14 (Безопасность и Валидация)
### 🛡 Безопасность (Security Update)
- **DB Hardening**: Порт базы данных `5432` закрыт от внешнего мира (ограничен `127.0.0.1` в Docker).
- **API Authentication**: Реализована глобальная проверка `X-TG-Init-Data`. Теперь FastAPI валидирует HMAC-SHA256 подпись Telegram для каждого запроса.
- **CORS Policy**: Настроены строгие правила CORS.
- **Frontend Authorization**: Все сетевые запросы Mini App (fetch) теперь автоматически включают заголовок авторизации.
### ⚙️ Frontend Refactoring
- **useTelegram Hook**: Добавлена передача `initData` для взаимодействия с API.
- **Global Config**: В `config.js` добавлена утилита `getApiHeaders` для централизованного управления заголовками.
- **Mass Update**: Обновлены все страницы (`Home`, `Profile`, `Orders`, `OrderDetail`, `NewOrder`) для работы с новой схемой авторизации.

## [1.2.0] — 2026-03-13 (Рефакторинг админки)
### 🤖 Telegram Bot & Admin Logic
- **Система алертов**: Реализованы мгновенные уведомления для администраторов о новых заказах.
- **Вложения**: Добавлена поддержка пересылки файлов (MediaGroup) из заявок админам.
- **Назначение исполнителей**: Реализована логика выбора исполнителя через Inline-кнопки прямо в чате админа.
- **Ожидающие заявки**: Добавлена кнопка «📋 Ожидающие заявки» для обработки пропущенных или старых заказов.
- **Автоматизация уведомлений**: Добавлена рассылка сообщений клиентам и исполнителям при назначении заказа.
- **Ролевая модель**: Улучшена логика регистрации — админы теперь автоматически получают расширенное меню.

### ⚙️ Backend & API
- **Глобальный Bot Instance**: Переработана инициализация бота для возможности импорта в API (FastAPI).
- **Синхронизация**: API теперь триггерит алерты в бот при создании заказа.
- **DB Service**: Добавлены методы `assign_executor`, `get_unassigned`, и `ExecutorService` для работы с базой.
- **Фикс багов**: Исправлены ошибки импортов, дублирование классов и отсутствие библиотек (`Path`, `datetime`).

### 🛠 Системные скрипты (`backend/utils/scripts/`)
- **`backup_db.py`**: Полноценный скрипт бэкапа для PostgreSQL v15 (Homebrew/MacOS).
- **`init_db.py`**: Скрипт перенесен и обновлен для работы с новыми путями.
- **`generate_test_data.py`**: Теперь генерирует не только клиентов, но и верифицированных исполнителей с профилями.

### 📂 Документация
- **Реструктуризация**: Полностью обновлена папка `docs/`.
- **INDEX.md**: Создана карта документов и правила обновления.
