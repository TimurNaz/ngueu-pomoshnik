# 🚨 Проблемы и Технический долг (Issues)

Этот файл — живой документ для отслеживания текущих проблем и планирования исправлений.

## ✅ Решенные критические проблемы

| # | Проблема | Описание | Решение |
| :--- | :--- | :--- | :--- |
| **1** | **Порт БД открыт** | Порт `5432` был доступен всему миру. | Ограничен localhost в `docker-compose.yml` |
| **2** | **Нет API Auth** | Эндпоинты не проверяли `initData`. | Внедрена HMAC-SHA256 валидация в FastAPI |
| **3** | **CORS: Wide Open** | `allow_origins=["*"]` был включен. | Настроены строгие `ALLOWED_ORIGINS` |
| **4** | **Broken API Link** | Фронтенд не видел бэкенд через ngrok. | Исправлен `API_BASE_URL` в `config.js` |
| **5** | **Hardcoded IDs** | Заглушка `927125510` мешала тестам. | Полностью удалена из фронтенда |

## 🟡 Серьезные проблемы (Medium Priority)

1. **MemoryStorage**: Нужно переключить бота на Redis (`db/redis.py`) для сохранения состояний при перезапуске.
2. **Ротация логов**: Ограничить логи Docker (max-size: 10mb).
3. **Хардкод**: Удалить `bot_username = "NGU_StudBot"` и другие константы в сервисах, вынести в `config.py`.
