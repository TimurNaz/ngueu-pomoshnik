# 🎨 Архитектура и Стили (Frontend)

Фронтенд реализован как **Telegram Mini App** (SPA) на базе React 18.

---

## 🏗 Структура проекта (`src/`)

```text
src/
├── components/         # Переиспользуемые компоненты
│   ├── ui/             # Атомарные элементы (badges, progress)
│   ├── onboarding/     # Слайды приветствия
│   ├── Layout.jsx      # Обертка с навигацией
│   └── Header.jsx      # Шапка приложения
├── pages/              # Основные экраны (Home, Orders, Profile...)
├── hooks/              # Кастомные хуки (useTelegram)
├── styles/             # Глобальные стили и переменные
└── config.js           # Настройки подключения к API
```

---

## 🌈 Дизайн-система (CSS Tokens)

Все ключевые значения вынесены в `src/styles/variables.css`.

### Основные цвета
- `--accent`: `#0a5f7a` — Главный цвет бренда.
- `--green`: `#b7f34a` — CTA и активные элементы.
- `--status-new`: `#b7f34a`
- `--status-progress`: `#f9a825`
- `--status-done`: `#4bc8e8`

### Радиусы и тени
- `--radius`: `14px` (стандарт для карточек).
- `--shadow-md`: `0 4px 16px rgba(0,0,0,0.08)`.

## 📄 Страницы и Пользовательский путь (Flows)

В Mini App реализовано 7 ключевых экранов:

1. **🚀 Онбординг** (`Onboarding.jsx`): 3 слайда приветствия, показываются один раз.
2. **🏠 Главная** (`Home.jsx`): Дашборд с балансом бонусов и последними заказами.
3. **📝 Создание заказа** (`NewOrder.jsx`): Трехшаговая форма (Тип -> Детали -> Сроки/Файлы).
4. **📋 Список заказов** (`Orders.jsx`): История заявок с фильтрацией по статусам.
5. **🔍 Детали заказа** (`OrderDetail.jsx`): Полная инфо по работе и прогресс-бар.
6. **👤 Профиль** (`Profile.jsx`): Реферальная программа и история бонусов.
7. **❓ FAQ** (`FAQ.jsx`): Аккордеоны с ответами на частые вопросы.

## 📏 Правила разработки
- **Методология**: BEM для именования CSS-классов.
- **Тактильная отдача**: Использование `haptic('impact', 'light')` при кликах на важные элементы.
- **Маршрутизация**: React Router v6.
