## ✨ Эффекты и Геометрия (Effects & Geometry)

### Скругления (Corner Radius)
- `radius-sm`: `8px` (небольшие элементы)
- `radius-md`: `12px` (кнопки, аккордеоны)
- `radius-lg`: `20px` (основные карточки из палитры)
- `radius-xl`: `24px` (крупные блоки, `cornerSmoothing: 0.6`)

### Тени (Drop Shadows)
- `shadow-default`: `0 8px 16px rgba(0, 0, 0, 0.1)`
- `shadow-large`: `0 8px 20px rgba(0, 0, 0, 0.1)` (для `Frame 517/518`)

---

## 📐 Сетка и Отступы (Spacing - по анализу фреймов)
- `padding-outer`: `32px` (внешние поля контейнеров палитры)
- `gap-medium`: `24px` (между крупными блоками)
- `gap-small`: `12px` (между элементами внутри блоков)
