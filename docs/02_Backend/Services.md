# ⚙️ Бизнес-логика (Service Layer)

Вся основная логика системы вынесена в сервисный слой (`backend/bot/services/db_service.py`). Это обеспечивает единство правил для Telegram-бота и API.

---

## 💎 Система лояльности и бонусы

### Уровни лояльности
Система автоматически пересчитывает уровень пользователя при каждой покупке:
- **novice**: 0 - 10,000₽ (3%)
- **apprentice**: 10,001 - 30,000₽ (5%)
- **expert**: 30,001 - 70,000₽ (7%)
- **master**: 70,001₽ + (10%)

### Правила использования бонусов
- **Регистрация**: 500 бонусных рублей новым пользователям.
- **Оплата**: Бонусами можно оплатить до **50%** стоимости заказа.

---

## 🛠 Ключевые сервисы

### `UserService`
- `get_or_create()`: Регистрация/авторизация. Автоматическая привязка роли админа.
- `send_admin_alert()`: Генерация алертов с поддержкой MediaGroup и кнопок назначения.
- `format_order_text()`: Единый стандарт отображения данных заказа.

### `OrderService`
- `create()`: Валидация данных и запись в БД.
- `assign_executor()`: Привязка исполнителя, смена статуса на `in_progress`.
- `get_unassigned()`: Выборка новых заказов для админ-панели.

### `ExecutorService`
- `get_available()`: Список верифицированных и активных исполнителей для назначения на заказы.

### `BonusService`
- `add()` / `spend()`: Атомарные операции с бонусным балансом.
- `apply_cashback()`: Расчет кешбэка по завершении заказа.
