# 🤖 Telegram Бот (aiogram 3)

Бот служит основной точкой входа для пользователей и администраторов.

---

## 🛠 Технологии
- **aiogram 3.x**: Асинхронный фреймворк для Telegram Bot API.
- **SQLAlchemy**: Интеграция с БД для управления пользователями.
- **WebAppInfo**: Запуск Mini App через кнопку меню и Inline-кнопки.

---

## ⌨️ Хендлеры и Команды

| Команда | Функционал | Статус |

---

## 🛡 Админ-функционал

Бот автоматически определяет администратора по ID (из переменной окружения `ADMIN_IDS`).
- **Уведомления**: При создании заказа админ получает сообщение с описанием и всеми файлами (MediaGroup).
- **Назначение**: Под описанием заказа выводятся кнопки с именами верифицированных исполнителей.
- **Синхронизация**: При нажатии кнопки статус заказа в БД меняется на `in_progress`, уведомления уходят клиенту и исполнителю.

---

## 🔄 Состояния (FSM)

Система использует `StatesGroup` для управления сложными диалогами:
- **ConsentState**: Ожидание подтверждения пользовательского соглашения.

---

## 📋 Клавиатуры

1. **Main Menu (Reply)**: Зависит от роли юзера (клиент/админ).
2. **Inline Keyboards**: Навигация в FAQ и выбор исполнителей в админке.
3. **Mini App Button**: Кнопка слева от поля ввода (Menu Button).
