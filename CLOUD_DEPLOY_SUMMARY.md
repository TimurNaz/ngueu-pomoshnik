## 🔑 SSH и Безопасность
*   **Локальные ключи:** На твоем Макбуке создана пара в `~/.ssh/id_rsa` (приватный) и `~/.ssh/id_rsa.pub` (публичный).
*   **Доступ:** Публичный ключ добавлен в Яндекс Облако, что позволяет заходить без пароля и деплоить через скрипт.
*   **GitLab Token:** ⚠️ В ходе сессии был засвечен Personal Access Token (`glpat-...`). 
    *   *Действие:* Нужно зайти в GitLab -> Preferences -> Access Tokens и **удалить (Revoke)** его, создав новый.

## 🚀 Метод Деплоя (CI/CD Status)
Мы не смогли использовать стандартные **GitLab Pipelines**, так как GitLab требует верификацию банковской карты для использования своих серверов.

**Текущее решение:** Скрипт `./deploy.sh` на твоем компьютере.
*   **Как работает:** Пушит код в GitLab -> Заходит по SSH на сервер -> Делает `git pull` -> Перезапускает Docker.
*   **Команда:** `./deploy.sh` (запускать из корня проекта на Маке).

## 🌐 Проблема HTTPS и MiniApp
Telegram требует HTTPS. Сейчас это решено через временный **Cloudflare Tunnel**.

1.  **Запуск туннеля (на сервере):** `cloudflared tunnel --url http://localhost:3000`
2.  **Актуальная ссылка:** Ищи в логах сервера строку `https://xxx.trycloudflare.com`.
3.  **Синхронизация:** Эту ссылку НУЖНО вставить в два места:
    *   В **@BotFather** (настройки кнопки меню).
    *   В файл **`.env` на сервере** (переменная `MINIAPP_URL`). После замены выполнить `docker compose up -d bot`.
